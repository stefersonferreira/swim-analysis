# Especificação

A spec completa da v1 (etapas 1 e 2) é um documento compartilhado:
https://claude.ai/code/artifact/a958ff0b-9bed-420b-9627-92c4e47990bb

Seções que guiam a implementação: Métricas (definições e fórmulas), Pipeline de visão
computacional, Calibração, Ferramenta de revisão, Guia de implementação (ordem de entregas e
critérios de pronto) e Dataset/critérios de aceite.

`schemas/` tem os contratos exportados como JSON Schema (gerados por
`tools/export_schemas.py`; não edite à mão).
