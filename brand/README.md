# Identidade visual Fluxi Swim

Usada na sobreposição ao vivo (tela de revisão) e no MP4 exportado. Os valores abaixo são a
fonte da verdade: `frontend/src/brand.css` e `pipeline/swimcv/overlay/style.py` repetem estes
tokens.

| Token | Valor | Uso |
| --- | --- | --- |
| navy | #0B1220 | fundo, painéis (82% de opacidade sobre o vídeo) |
| panel | #111C33 | cartões |
| mint | #6EE7B7 | destaque principal, brilho, marcador do nadador |
| sky | #7CC4FA | destaque secundário, degradê mint → sky |
| text | #EAF2FF | números e textos |
| muted | #9FB0CC | rótulos |
| amber | #F5A524 | selos (piscina atual, recorde) |

Tipografia: **Fredoka** (títulos e números, peso 600–700) e **Nunito** (rótulos, peso 700–800).
Cantos de 18 px nos cartões, pílulas totalmente arredondadas, brilho menta suave.

Fontes: Google Fonts, licença SIL Open Font License 1.1 (arquivos OFL-*.txt nesta pasta).
